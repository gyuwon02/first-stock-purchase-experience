# Raw Observations

> 주요 증권 플랫폼에서 동일한 첫 주식 매수 과업을 수행하며
> 실제 화면에서 확인한 내용과 사용 과정에서 발생한 질문을 기록한다.
>
> Observation은 화면에서 직접 확인한 사실을 중심으로 작성하며,
> 개인적인 사용 경험은 Researcher Note로 구분한다.
> 아직 일반 사용자의 문제나 최종 Finding으로 확정하지 않는다.


# 1. Toss Securities

## Test Context

- Task: 삼성전자 주식 1주 구매 시도
- Start: 토스증권 메인 화면
- End: 주문 단계 확인
- User perspective: 주식 거래 경험이 적은 사용자의 관점에서 수행

## 1-1. 증권 홈

### User Goal
삼성전자 종목을 찾는다.

### User Action
증권 홈 우측 상단의 검색 버튼을 선택한다.

### Observation
- 증권 홈 상단에 검색 버튼이 위치한다.
- 기본계좌의 원화·달러 잔액이 표시된다.
- 주문내역, 판매수익, 배당금 메뉴가 제공된다.
- 최근 본 종목 영역이 제공된다.

### Researcher Note
- 종목 검색 기능을 찾는 과정에서는 별다른 어려움이 없었다.


---

## 1-2. 종목 검색

### User Goal
삼성전자 종목을 찾는다.

### User Action
검색창에 '삼성전자'를 입력한다.

### Observation
- 검색 결과 상단에 '삼성전자'와 '삼성전자우'가 노출된다.
- 그 아래에는 삼성전자가 포함된 ETF 및 레버리지 상품 등이 함께 노출된다.
- 각 검색 결과에는 상품명과 아이콘이 표시된다.

### Question
- 주식 경험이 적은 사용자는 삼성전자, 삼성전자우,
  관련 ETF·레버리지 상품의 차이를 검색 결과만으로 구분할 수 있는가?


---

## 1-3. 종목 상세 진입

### User Goal
삼성전자에 대한 정보를 확인한다.

### User Action
검색 결과에서 '삼성전자'를 선택한다.

### Observation
- 종목명과 현재 가격이 화면 상단에 크게 표시된다.
- 전일 대비 가격 변화와 등락률이 함께 표시된다.
- '실시간 주문 가능' 여부가 표시된다.
- 차트가 기본 화면으로 제공된다.
- 차트 / 호가 / 내 주식 / 종목정보 / 커뮤니티 탭이 제공된다.
- 화면 하단에 '구매하기' 버튼이 고정되어 있다.
- 차트 기간을 1일, 1주, 3달, 1년, 5년, 전체로 변경할 수 있다.

### Researcher Note
- 현재 가격과 구매 버튼이 눈에 잘 띄어 다음 행동을 찾기는 어렵지 않았다.

## 1-4. 종목 정보 탐색

### User Goal
삼성전자를 구매하기 전에 관련 정보를 확인한다.

### User Action
종목 상세 화면을 아래로 스크롤한다.

### Observation
- '왜 올랐을까?' 영역에서 최근 가격 움직임과 관련된 내용을 제공한다.
- '10초 요약 보기' 영역이 제공된다.
- 소식과 호재 등의 라벨을 이용해 정보를 구분한다.
- 관련 커뮤니티 의견을 같은 종목 상세 화면에서 확인할 수 있다.
- 화면 하단의 '구매하기' 버튼은 스크롤 중에도 유지된다.

### Question
- 투자 경험이 적은 사용자는 매수 전에 어떤 정보를 우선적으로 확인할까?
- 뉴스, 요약정보, 커뮤니티 의견 중 어떤 정보를 투자 판단에 필요한 정보로 인식할까?

## 1-5. 구매 화면

### User Goal
삼성전자 1주 구매를 시도한다.

### User Action
'구매하기' 버튼을 선택한다.

### Observation
- '구매할 가격'과 '수량'이 주요 입력 항목으로 제공된다.
- 구매 가격 옆에 '현재가'가 표시된다.
- 구매 가능한 금액과 최대 구매 가능 수량이 표시된다.
- 수량 입력 화면에서 10%, 25%, 50%, 최대 버튼이 제공된다.
- '미수거래' 선택 항목이 제공된다.
- 좌측 하단에 '호가' 버튼이 제공된다.
- 우측 상단에 '주문 방법 바꾸기'가 제공된다.

### Researcher Note
- 가격과 수량을 입력해야 한다는 점은 바로 이해할 수 있었다.
- 반면 '호가', '미수거래', '주문 방법'과 같은 개념은
  주식 거래 경험이 적은 입장에서 의미를 추가로 확인할 필요가 있었다.

## 1-6. 미수거래 안내

### User Goal
주문 화면에 표시된 '미수거래'가 무엇인지 확인한다.

### User Action
'미수거래' 항목을 선택한다.

### Observation
- 별도의 미수거래 안내 화면으로 이동한다.
- '미수로 더 구매할까요?'라는 제목을 사용한다.
- '빌린 돈은 2일 뒤 결제일까지 갚으면 돼요.'라고 설명한다.
- 계좌에 100만원이 있고 주식 가격이 10만원인 상황을 예시로 제시한다.
- 계좌에 있는 돈으로 구매할 경우 최대 10주,
  미수거래를 이용할 경우 현금 30%를 내고 최대 33주를
  구매할 수 있다는 차이를 보여준다.
- 하단에 '미수거래 시작하기'와 '닫기'가 제공된다.

### Researcher Note
- '미수거래'라는 용어 자체는 처음 봤을 때 바로 이해하기 어려웠다.
- 안내 화면에서는 금액과 주식 수를 예로 들어 기본 개념을 이해하기 쉬웠다.


---

## 1-7. 미수거래 상세 설명 확인

### User Goal
미수거래의 정확한 내용을 추가로 확인한다.

### User Action
'미수거래 시작하기'를 선택한 뒤 필수 동의 화면에서
'미수거래 설명서'를 선택한다.
실제 서비스 동의 및 신청은 진행하지 않는다.

### Observation
- 미수거래를 시작하기 위해 별도의 필수 서비스 이용 동의가 요구된다.
- 동의 단계에서 '미수거래 설명서'를 확인할 수 있다.
- 설명서를 선택하면 별도의 웹 화면에서 PDF 형태의 설명서가 열린다.
- 따라서 간단한 안내 이후 상세한 정보를 추가로 확인할 수 있는 구조이다.

### Researcher Note
- 기본적인 개념 설명은 앞 단계에서 이해하기 쉬웠지만,
  정확한 내용을 확인하려면 별도의 설명서를 읽어야 했다.
- 첫 진입과 구매 흐름 자체는 간단하게 느껴졌지만,
  거래와 관련된 개념을 하나씩 정확하게 이해하는 것은 별개의 문제라고 느꼈다.

> 현재 내용은 개인의 1차 사용 경험이며,
> 다른 투자 초보자에게 동일하게 발생하는 문제로 확정하지 않는다.

## 1-8. 주문 방법 확인

### User Goal
삼성전자 구매 시 이용할 수 있는 주문 방법을 확인한다.

### User Action
구매 화면에서 '주문 방법 바꾸기'를 선택한다.

### Observation
- 주문 방법은 다음 5가지로 구분되어 제공된다.
  - 일반 주문
  - 정규장 주문 예약
  - 빠른 주문
  - 조건 주문
  - 주식 모으기
- 현재 선택된 '일반 주문'에는 체크 표시가 제공된다.
- '정규장 주문 예약'에는 '다음 정규장이 시작되면 주문'이라는 설명이 제공된다.
- '빠른 주문'에는 '한 화면에서 빠르게 구매와 판매 주문하기'라는 설명이 제공된다.
- '조건 주문'에는 '가격과 주문 기간을 설정하면 자동 주문'이라는 설명이 제공된다.
- '주식 모으기'에는 '매일·매주·매달 원하는 주기마다 주문'이라는 설명이 제공된다.

### Researcher Note
- 주문 방법의 명칭만 제시하지 않고 각 기능의 목적을 한 문장으로 함께 설명하고 있다.
- 다만 처음 주식 1주를 구매하려는 상황에서는 여러 주문 기능 중
  어떤 기능이 필요한지 판단해야 한다.
- 기본값이 '일반 주문'으로 설정되어 있어 다른 주문 방식을 반드시
  선택해야 구매를 진행하는 구조는 아니다.

## 1-9. 호가 확인

### User Goal
구매 화면에 표시된 '호가'가 무엇인지 확인한다.

### User Action
구매 화면에서 '호가'를 선택한다.

### Observation
- 여러 가격대와 각 가격대에 대응하는 수량이 표시된다.
- 현재 선택된 가격이 별도로 강조된다.
- 구매할 가격을 직접 조정할 수 있다.
- 별도의 상세 주문 화면에서는 주문과 대기 영역이 구분되어 제공된다.
- 상세 화면에는 구매 가능 금액, 예상 구매 금액,
  미수거래 여부 등이 함께 표시된다.
- 현재가 구매와 시장가 구매 기능이 별도로 제공된다.
- 체결강도, 판매 대기, 구매 대기 등의 정보도 표시된다.

### Researcher Note
- 호가 화면을 여는 것 자체는 어렵지 않았다.
- 그러나 가격 옆의 수량, 체결강도, 판매 대기·구매 대기,
  현재가와 시장가의 차이 등은 주식 거래 경험이 적은 입장에서
  화면만 보고 바로 의미를 이해하기 어려웠다.
- 기본 구매 화면과 비교하면 한 화면에서 확인해야 하는 정보의 양이 크게 증가했다.

## 1-10. 추가 주문 기능 확인

### User Goal
일반 주문 외에 어떤 거래 기능이 제공되는지 확인한다.

### User Action
'주문 방법 바꾸기'에서 조건 주문과 주식 모으기를 확인한다.

### Observation

#### 조건 주문
- 별도의 조건 주문 화면으로 이동한다.
- 기존 조건 주문이 없는 경우 '조건 주문 추가하기' CTA를 제공한다.

#### 주식 모으기
- 종목별로 모을 수량을 설정할 수 있다.
- 주문 주기를 설정할 수 있다.
- 화면 예시에서는 '매일'이 기본적으로 표시된다.
- '이대로 모으기' CTA가 제공된다.

### Researcher Note
- 단순 매수 외에도 예약·자동·반복 주문 등 다양한 거래 방식이 제공된다.
- 다만 이번 프로젝트의 핵심 Task는 '삼성전자 1주 첫 구매'이므로
  해당 기능들의 세부 설정 과정까지는 조사 범위에 포함하지 않는다.

## 1-11. Toss Initial Notes

### Navigation
- 증권 홈에서 종목 검색, 종목 상세, 구매 화면으로 이어지는
  주요 행동 경로는 비교적 명확했다.
- 현재가와 구매 CTA 등 주요 행동 요소가 눈에 띄게 제공되었다.

### Information Support
- 종목 상세에서는 '왜 올랐을까?', '10초 요약' 등
  투자정보를 요약해서 제공하는 기능을 확인했다.
- 미수거래처럼 별도 설명이 필요한 기능에는
  예시를 활용한 안내 화면과 상세 설명서가 제공되었다.
- 주문 방법 선택에서도 각 기능에 대한 짧은 설명이 함께 제공되었다.

### Complexity
- 기본 구매 화면은 가격과 수량을 중심으로 비교적 단순하게 구성되어 있다.
- 반면 호가 및 상세 주문 화면으로 이동하면 체결강도,
  판매·구매 대기, 시장가 등 추가적인 거래 정보가 노출된다.
- 따라서 '다음 행동을 찾는 것'과 '화면에 표시된 금융정보를 이해하는 것'은
  서로 다른 문제일 가능성이 있다고 느꼈다.

### Researcher Reflection
첫 매수 과정에서 무엇을 눌러야 하는지는 비교적 쉽게 찾을 수 있었다.
반면 기능을 하나씩 자세히 살펴볼수록 주식 거래에 대한 사전지식이
필요한 정보가 증가했다.

이는 현재 연구자의 개인 사용 경험을 기반으로 한 초기 관찰이며,
다른 사용자에게 동일하게 나타나는 문제로 확정하지 않는다.
카카오페이증권과 M-STOCK에서 동일한 Task를 수행한 뒤
서비스 간 공통점과 차이를 비교한다.

# 2. KakaoPay Securities

## 2-1. 증권 홈 진입

### User Goal
삼성전자 주식을 찾기 위해 종목 검색 기능을 찾는다.

### User Action
증권 홈에 진입한 뒤 상단 검색 아이콘을 선택한다.

### Observation
- 증권 홈 상단에 검색 아이콘이 제공된다.
- 홈 화면에는 투자지원금 프로모션, 주식모으기, ISA, 연금,
  실시간 상승 등의 메뉴가 함께 노출된다.
- 하단에는 증권홈, 관심, 발견, 소식 메뉴가 제공된다.
- 토론방 인기글 등 투자자 커뮤니티 콘텐츠도 홈에서 확인할 수 있다.

### Researcher Note
- 검색 아이콘의 위치가 상단에 있어 종목 검색 기능 자체는 쉽게 찾을 수 있었다.
- 동시에 홈 화면에서 프로모션, 금융상품, 커뮤니티 등 다양한 콘텐츠가 함께 노출된다.


---

## 2-2. 삼성전자 검색

### User Goal
삼성전자 종목을 찾는다.

### User Action
검색창에 '삼성전자'를 입력한다.

### Observation
- 검색 진입 화면에는 인기 검색어, 인기 AI 인사이트,
  매매인증이 많은 커뮤니티 등의 콘텐츠가 제공된다.
- '삼성전자' 검색 후 주식 검색 결과가 별도 영역으로 제공된다.
- 삼성전자와 삼성전자우가 함께 노출된다.
- 종목명 아래 종목코드가 표시된다.
- 검색 결과에는 삼성전자가 포함된 ETF와 펀드도 별도 영역으로 제공된다.

### Researcher Note
- 삼성전자 자체를 찾는 것은 어렵지 않았다.
- 동일 검색어에 주식뿐 아니라 ETF·펀드까지 함께 제공되어
  사용자가 관련 금융상품을 탐색할 수 있는 구조였다.
- 주식 경험이 적은 사용자가 '삼성전자'와 '삼성전자우',
  개별주식과 삼성전자가 포함된 ETF의 차이를 알고 있는지는
  별도로 확인할 필요가 있다.

## 2-3. 종목 상세 진입

### User Goal
삼성전자의 현재 가격과 투자 정보를 확인한다.

### User Action
검색 결과에서 삼성전자를 선택한다.

### Observation
- 상단에 현재 가격과 등락률이 크게 표시된다.
- '정보 / 차트 / 호가 / 보유 / 토론' 탭이 제공된다.
- 정보 영역에는 거래량과 시가총액이 표시된다.
- 하단에 판매와 구매 CTA가 고정되어 있다.
- 정보 내부에는 요약, 시세, 뉴스, 거래동향, 배당, 실적, 개요 등의
  세부 메뉴가 제공된다.

### Researcher Note
- 현재 가격과 구매 CTA는 눈에 띄게 배치되어 있어
  구매 행동으로 이동할 위치는 쉽게 확인할 수 있었다.
- 반면 종목 상세에서 확인할 수 있는 정보의 종류가 많고,
  상위 탭과 정보 내부의 세부 메뉴가 동시에 제공된다.

## 2-4. 종목 요약 정보 확인

### User Goal
삼성전자 주가 변동 이유와 현재 주요 정보를 확인한다.

### User Action
정보 > 요약 영역을 확인한다.

### Observation
- 주가 변동에 대한 AI 분석 문장이 상단에 제공된다.
- 분석 기준 시점이 함께 표시된다.
- '지금 이슈' 영역에서 기관 매매, 사용자 수익 인증,
  인기 랭킹 등의 정보가 제공된다.
- 토론방으로 이어지는 콘텐츠도 함께 제공된다.

### Researcher Note
- 주가 변동 이유를 자연어 문장으로 요약해 제공한다는 점은
  초보자가 정보를 탐색하는 방식에서 확인할 가치가 있다.
- 동시에 AI 분석, 기관 매매, 다른 사용자의 수익 인증,
  인기 랭킹 등 성격이 다른 정보가 한 화면에 함께 제공된다.
- 어떤 정보가 실제 투자 판단에 필요한 정보로 인식되는지는
  현재 단계에서는 판단하지 않는다.

## 2-5. 시세 정보 확인

### User Goal
삼성전자의 실제 거래 현황을 확인한다.

### User Action
정보 > 시세를 선택한다.

### Observation
- 실시간 체결 내역이 시간, 체결가, 체결량, 방향으로 제공된다.
- 일별 시세에는 날짜별 종가, 등락률, 등락금액 등의 정보가 제공된다.
- 상세 데이터를 추가로 볼 수 있는 '더보기' 기능이 제공된다.

### Researcher Note
- 실시간 거래 데이터를 직접 확인할 수 있다.
- '체결', '체결량', '방향' 등 주식 거래 관련 용어에 대한
  별도의 설명은 현재 확인한 화면에서는 보이지 않았다.

## 2-6. 차트 확인

### User Goal
삼성전자의 가격 흐름을 확인한다.

### User Action
상단 '차트' 탭을 선택한다.

### Observation
- 캔들 차트가 기본적으로 제공된다.
- 이동평균선 5·20·60·120과 SMA가 표시된다.
- 60틱, 5분, 일, 주, 월 등 차트 기준을 변경할 수 있다.
- 거래량 차트가 함께 제공된다.
- 하단에 차트 주문, 판매, 구매 CTA가 제공된다.

### Researcher Note
- 다양한 차트 정보를 한 화면에서 확인할 수 있다.
- 이동평균선, SMA, 틱 등 투자 경험이 없는 사용자가
  별도 지식 없이 의미를 이해할 수 있는지는 확인이 필요하다.
- 차트에서도 구매 행동으로 바로 이동할 수 있는 CTA는 명확하게 제공된다.

## 2-7. 호가 및 구매 단계 접근 제한

### User Goal
삼성전자 1주 구매를 위해 호가 및 주문 화면을 확인한다.

### User Action
호가 및 구매 기능 진입을 시도한다.

### Observation
- 해당 단계의 전체 기능을 이용하려면 증권계좌 개설이 필요했다.
- 조사자는 계좌를 개설하지 않은 상태이므로
  호가 및 실제 주문 단계 이후의 화면은 확인하지 않았다.

### Researcher Note
- 카카오페이증권에서는 비계좌 사용자가 종목 검색 및
  상당 부분의 투자정보를 확인할 수 있었지만,
  실제 거래 기능 조사에는 계좌 개설이라는 선행조건이 존재했다.
- 따라서 주문 화면의 정보 구조 및 주문 완료 과정은
  이번 직접 관찰만으로 토스증권과 비교하지 않는다.

### Research Limitation
카카오페이증권의 주문 단계는 직접 관찰하지 못했으므로
'카카오페이증권의 주문 과정이 더 복잡하다/간단하다'와 같은
서비스 간 결론을 내리지 않는다.

# 3. M-STOCK

## 3-1. 서비스 접근

### User Goal
삼성전자 종목을 검색하고 첫 매수 과정을 확인한다.

### User Action
M-STOCK에서 주식 거래를 위한 계좌 개설을 시도했다.

### Observation
- 비대면 계좌 개설 과정에서 본인확인이 요구됐다.
- 조사자의 안심차단 등록 상태로 인해 비대면 계좌 개설을 진행할 수 없었다.
- 안내 화면에서는 안심차단 해제를 위해 서비스를 신청한 금융기관 또는 주거래은행 방문이 필요하다고 안내했다.
- 따라서 종목 탐색부터 주문까지의 동일 과업을 직접 수행하지 못했다.

### Researcher Note
- M-STOCK은 조사 환경상 동일 조건의 직접 관찰 데이터를 확보하지 못했다.
- 확인하지 못한 화면을 외부 자료나 추측으로 보완하여 직접 관찰 결과처럼 사용하지 않는다.

### Research Limitation
M-STOCK의 실제 종목 탐색 및 주문 경험은 이번 직접 관찰 비교에서 제외한다.
따라서 M-STOCK과 토스증권·카카오페이증권 사이의 사용성을 직접 비교하지 않는다.
