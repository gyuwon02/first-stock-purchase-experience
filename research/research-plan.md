# 조사 계획

## 조사 질문

투자 경험이 적은 사용자는 처음 주식 1주를 매수하는 과정에서
어떤 정보와 행동을 요구받으며,
서비스별 정보 제공 방식에는 어떤 차이가 있는가?


## 대상

주식 거래 경험이 없거나 매우 적은 사용자


## 대상 서비스

Toss Securities
KakaoPay Securities
Mirae Asset M-STOCK


## 과업 시나리오

주식 투자 경험이 거의 없는 사용자가
삼성전자 주식 1주를 처음 구매하려고 한다.


## 시작 지점

앱 메인 화면


## 종료 지점

주문 단계 확인


## 관찰 범위

종목 탐색
→ 종목 정보 확인
→ 매수 진입
→ 주문 방식 확인
→ 가격·수량 입력
→ 주문 단계 확인
