# 처음 주식을 사는 사람은 어디에서 멈출까?

> 국내 증권 앱 3사의 종목 탐색부터 첫 매수까지 직접 따라가며,
> 투자 경험이 적은 사용자가 정보를 이해하고 행동하는 과정에서
> 어떤 어려움을 마주하는지 살펴봅니다.

## 왜 이 프로젝트를 시작했나

주식을 처음 사려고 하면 '구매' 버튼을 누르는 것보다
그 전에 무엇을 봐야 하는지 판단하는 일이 더 어렵습니다.

현재가, 호가, 체결량, 시장가와 지정가처럼
익숙하지 않은 정보가 등장하고,
같은 주식을 구매하는 과정도 서비스마다 정보를 보여주는 방식이 다릅니다.

그래서 이 프로젝트에서는 특정 증권 앱의 사용성을 평가하기보다,
**'주식을 처음 사는 사람은 실제 매수 과정에서 무엇을 보고,
어디에서 추가적인 이해가 필요해지는가?'**를 확인하고자 했습니다.

## 무엇을 비교하나

동일한 과업을 기준으로 토스증권, 카카오페이증권, M-STOCK을 살펴봅니다.

**Task**

> 삼성전자 1주를 처음 구매한다고 가정하고,
> 종목을 검색한 뒤 필요한 정보를 확인하고 주문 단계까지 진행한다.

관찰 범위는 다음과 같습니다.

`종목 탐색 → 종목 정보 확인 → 매수 결정 → 주문 → 결과 확인`

실제 계좌가 필요한 기능은 임의로 가입하지 않고,
비회원 또는 현재 이용 가능한 범위까지만 확인합니다.

## 이 프로젝트에서 만들 것

단순히 세 앱의 화면을 비교하는 것으로 끝내지 않습니다.

1. 동일 과업을 수행하며 실제 화면과 행동 흐름 기록
2. 서비스별 정보 구조와 사용자 흐름 비교
3. 투자 초보자가 추가적인 이해나 판단을 필요로 하는 지점 발견
4. 핵심 문제 정의
5. 개선 방향 및 화면 설계
6. 프로토타입 제작
7. 간단한 사용자 테스트 후 개선
